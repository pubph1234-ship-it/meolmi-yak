# 멀미시러 팀 · 멀미약 0.2.1 시연 안내

제출 영상은 68초이며, 앱에서 기록하는 가상 주행은 60초입니다. 영상 시간과 앱의 주행 시계가 다릅니다.

1. 홈에서 ‘변화가 큰 운전’을 선택하고 ‘비교용 가상 체감 자동 입력’을 켠 뒤 ‘60초 시연 시작’을 누릅니다.
2. 가상 경로의 회전·방지턱 안내와 속도 변화를 확인합니다. 주행 시계 42초에 비교용 가상 불편 입력이 자동으로 기록됩니다.
3. 이동 후 리포트에서 다음 운전 목표를 확인합니다. 영상의 약 52초부터 불편 입력 직전 구간(주행 22~42초)을 보여줍니다. 가속 변화 0회, 감속 변화 1회, 조향 변화 0회이며 해당 구간의 안내 2회는 운전 변화 집계에서 제외합니다.
4. 리포트는 관찰된 감속 변화를 바탕으로 교통 상황이 허용할 때 감속을 미리 준비하도록 제안합니다. 임상적 효과와 원인 관계는 후속 검증 대상입니다.

앱에서는 ‘미리 준비한 운전’도 선택할 수 있습니다. 같은 시각에 가상 체감을 입력해 두 운전 방식의 기록을 비교할 수 있습니다. 체감 버튼을 직접 사용하려면 자동 입력을 끕니다.

영상의 설명 음성은 편집 과정에서 추가한 내레이션입니다. 0.2.2 앱은 경로 안내 시 한국어 음원을 직접 재생합니다. 정차 상태에서 ‘연결 · 설정 → 안내 음성 미리 듣기’로 확인할 수 있습니다.
