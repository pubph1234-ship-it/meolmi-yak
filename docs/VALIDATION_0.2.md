- 20초는 시제품의 돌아보기 범위이며 임상적으로 검증된 멀미 반응 시간 기준이 아닙니다.

- Android 9 에뮬레이터에서 이전 release 위에 업데이트 설치가 성공했고 versionCode 2 / 0.2.0을 확인했습니다.
