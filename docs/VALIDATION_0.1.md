## Pleos Connect 에뮬레이터

공식 Connect 2.x 이미지(Android 14, release_connect_v2.1.0), Windows WHPX, 1280×720, RAM 2GB 환경입니다. 이미지 기본 RAM 설정은 8GB지만 테스트 PC 메모리 사정으로 낮췄습니다.

- 제출 release APK 설치와 사용자 10에서 Activity 실행 성공.
- 홈 화면, 설정 화면, 시연/차량 모드 전환 표시를 확인했습니다.
- 설정 화면에서 **AAOS 속도 수신 중**, **Vehicle SDK 조향각 수신 중**을 확인했습니다. 정차 상태의 수신 확인이며 주행 중 정확도 검증이 아닙니다.
- 시스템에서 P단/0 km/h 상태가 표시됐습니다.
- 계측 테스트는 `Process crashed`로 종료되어 **통과로 처리하지 않았습니다**. 같은 환경에서 profile HAL, carwatchdogd, audioserver의 시스템 오류가 관찰됐습니다. 테스트 종료의 원인을 특정하지는 않았습니다.
- 실제 경로의 TBT/주의 지점 이벤트와 음성, 움직이는 차량 신호 변화, 주행 제한 전환의 전체 검증은 완료하지 않았습니다.

## 일반 Android 실행 검증

공식 AOSP Android 9(API 28), 1280×800 에뮬레이터에서 확인했습니다.

- Android 계측 테스트 **3개 통과**: 시연 시작→체감 입력→리포트, 최근 기록 저장·복원, 동승자 통신의 유효 입력 및 잘못된 토큰/출처/비활성 상태 거부.
- 위 계측 테스트는 debug 빌드에서 실행했습니다. 핵심 로직 테스트와 합쳐 총 16개가 통과했습니다.
- 제출 release APK를 별도로 새 설치하고 홈·설정·시연 화면을 직접 확인했습니다. 회전 안내와 체감 입력이 제공됩니다.
- release에서 60초 시연 자동 종료 후 리포트의 주행 변화 4회, 직접 입력한 동승자 체감 1회, 속도 그래프와 다음 이동 목표 표시를 확인했습니다.
- 한국어 TTS가 없는 환경에서는 설정에 해당 상태를 표시하고 화면 안내를 유지했습니다. 음성 출력을 검증한 것은 아닙니다.
- 동승자 브라우저 UI의 직접 검증은 Browser 도구의 네트워크 정책 전달 오류로 완료하지 못했습니다. 서버 계측 테스트 통과와 브라우저 전체 흐름 검증은 구분합니다.
